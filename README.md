# Mobile-App-User-Engagement-Analytics
Mobile app engagement and subscription analysis using Python and Power BI
Mobile App User Engagement and Subscription Analytics

Project Overview

This project focuses on analyzing mobile application user interactions and subscription patterns using Python and Power BI. I explored user engagement, device usage, event activities, and subscription trends to identify meaningful insights.

Tools & Technologies

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Google Colab
- Microsoft Power BI

Project Workflow

1. Dataset inspection and validation
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Data visualization
5. Power BI dashboard development
6. Insight generation

Dataset Information

- Original records: 100,000
- Cleaned records: 98,656
- Columns: 21

Key Findings

- Android recorded more interactions than iOS.
- Click was the most frequent event type.
- Xiaomi Mi 11 was the leading device model.
- The checkout button received the highest interactions.
- Subscription distribution was almost evenly split.
